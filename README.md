# 稷下学宫

**召集任意时代的思想者，由你主持一场思想实验。**

战国时期，齐国稷下汇聚百家之学——不是为了找到答案，而是让不同的思维框架正面碰撞。今天，你来选人，你来出题，你来引导争鸣。

---

## 你不是旁观者，你是主持人

扔一个议题进去，不是为了得到"正确答案"——而是看同一个问题，被孔子、马基雅维利、芒格各自过一遍之后，会产生什么样的分歧，什么样的权衡，什么样的盲点。

**过程比结论更值钱。**

精英如何权衡？如何被对方观点触动？如何坚守或修正立场？这些是你在任何地方都看不到的东西。

你可以：
- **开场提问**：带着你自己的初步判断进来，让人格们针对你的具体切入点展开——而不是泛泛而谈
- **中途插话**：在讨论跑偏、或某个观点值得深挖的时候，随时把争鸣拉向你感兴趣的方向

---

## 能做什么

**决策压力测试**
> 「我打算放弃稳定工作，押注一个还没验证的想法——值得吗？」
> 召唤：芒格 · 马基雅维利 · 孙子
>
> 芒格会先问你有没有能力圈、有没有安全边际；马基雅维利会问你的对手是谁、背刺风险在哪；孙子会说你还没想清楚退路。没有一个人会直接告诉你"去吧"——但你听完，会比之前想得深很多。

**精英决策推演**
> 「特朗普、万斯、卢比奥，针对伊朗，下一步会怎么走？」
>
> 不是为了得到预言。而是看三种截然不同的权力观——交易型、民粹型、建制型——如何推导出看似相似、实则路径迥异的结论。观察他们的分歧，比观察结论本身更有价值。

**复杂议题切面**
> 「AI 会取代人类创造力吗？」
> 召唤：费曼 · 庄子 · Naval
>
> 费曼会先质问你"创造力"这个词你能不能解释清楚；庄子会说这个问题本身是个陷阱；Naval 会说取不取代不重要，重要的是谁先用它建立杠杆。三个人没有一个在回答你的问题——但你会发现自己其实问错了。
